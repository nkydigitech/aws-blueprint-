Okay, but what IS cloud and AWS really?

If the repo confused you, this is the part it was missing. Let's use Ikorodu logic.

🏠

1. What is "Cloud"?

Before cloud: You buy a big generator, fuel it, maintain it yourself just to power your small shop. That's owning servers.

Cloud: You connect to IKEDC. You use light, you pay for what you use, someone else maintains the grid. Cloud = renting computers, storage and network on the internet instead of buying your own.

☁️

2. What is AWS then?

AWS (Amazon Web Services) is Amazon's IKEDC for computers. It's the biggest warehouse in the world renting you 200+ services: computers (EC2), warehouses to store files (S3), security bouncers (IAM), traffic police (Load Balancer), phonebook (Route53).

Why it's #1: 33% of the whole internet runs on AWS — Netflix, Jumia, banks, your favorite apps.

What is AWS FOR?

• Host websites without buying servers
• Store unlimited files (like Google Drive for apps)
• Run apps that auto-scale when 10k users rush in
• Keep data safe with backups & alarms

Who NEEDS it?

• IT Support → Cloud Engineer (you!): Career upgrade
• Students: Build portfolio that employers believe
• Small Business: Your shop site online for ₦0 to start
• Founders/Devs: Launch without buying hardware

The 7 Core Concepts You Must Know First

We added this because the old page skipped it. This is what every beginner Googles at 2am.

🏭 EC2 = Rent-a-Computer

A virtual computer in Amazon's datacenter. You rent t2.micro (free tier) for 1 hour or 1 year. Lab 1.

🌍 Region & AZ = Branches

AWS has warehouses worldwide. Region = Lagos vs London. AZ = Ikeja vs Yaba branch — if one burns, other works. Lab 2.

🏘️ VPC = Fenced Estate

Your private estate in AWS cloud. You decide who enters, which rooms are public/private. Lab 3.

🪪 IAM + Security Group = Bouncers & ID Cards

IAM = who you are. Security Group = which door they can enter. No bouncer, no entry. Lab 4.

📦 S3 = Infinite Warehouse

Store images, videos, website files. Pay per GB. Never full. Lab 5.

📚 RDS = Robot Librarian

Database that patches itself, backs itself up. You just store data. Lab 6.

🚦 ALB + Auto Scaling = Smart Traffic

When your cybercafé is full, ALB brings more computers automatically. When empty, it reduces them. Lab 7-9.

Cost & Honest Expectations

💰 Will AWS charge me?

All labs run on AWS Free Tier (12 months free). t2.micro, S3 5GB, RDS 750hrs — free if you clean up. The expensive resources are ones you forget to delete (NAT Gateway, ALB). We warn you before you create them and give you delete command.

For Nigeria: Use a virtual dollar card, set budget to $5. Turn off resources after each lab — don't leave EC2 running overnight like gen.
